herdr keybindings
=================

Live keymap: prefix+?    Docs: https://herdr.dev/docs/
Prefix: ctrl+b, then release and press the action key.

Start and session
-----------------
  h                       start or attach
  hr <host>               attach remotely
  prefix+q                detach; processes keep running

Direct keys
-----------
  ctrl+shift+t             new tab
  ctrl+shift+left/right    previous/next tab
  ctrl+shift+up/down       previous/next workspace
  ctrl+shift+n             new workspace
  ctrl+shift+[/]           previous/next agent
  ctrl+shift+b             toggle sidebar
  ctrl+shift+r             resize mode

  ctrl+shift+h/j/k/l       focus pane left/down/up/right
  ctrl+shift+enter         split right
  ctrl+shift+d             split down
  ctrl+shift+backspace     close pane
  ctrl+shift+z             zoom pane
  ctrl+shift+,/.           previous/next pane

  ctrl+shift+o             OpenCode in a new tab at the active directory
  ctrl+shift+p             Pi in a new tab at the active directory
  F1                       edit scrollback

Prefix keys
-----------
  prefix+w                 workspace picker
  prefix+g                 goto picker
  prefix+[                 keyboard copy mode
  prefix+shift+p           rename pane
  prefix+shift+t           rename tab
  prefix+1..9              jump to tab
  prefix+shift+x           close tab
  prefix+shift+w           rename workspace
  prefix+shift+d           close workspace
  prefix+shift+g           new worktree
  prefix+s                 settings
  prefix+shift+r           reload config
  prefix+?                 show keymap

Scrollback and search
--------------------
  F1                       edit pane scrollback (replaces prefix+e)
  prefix+[                 enter copy mode
  / or ?                   search forward/backward in copy mode
  n / N                    next/previous search match
  prefix+?                 searchable live keybinding help

Herdr retains 10 MB of scrollback per pane by default. Tune
advanced.scrollback_limit_bytes in herdr.nix if needed; Kitty's 30,000-line
scrollback setting does not control Herdr pane history. Alternate-screen TUIs
do not necessarily retain output that has scrolled off their screen.

Shell and agents
----------------
  hrf COMMAND [ARGS...]    run in a new tab and focus it
  hrn COMMAND [ARGS...]    run in a new background tab
Both preserve the caller's workspace and directory, not the UI-focused tab.
Agent shortcuts use Herdr's readiness-aware agent start API. Delegated tasks
use agent prompt --wait --timeout, not shell prompt scraping. OpenCode and Pi
share version-matched skills and a local named-tab/authentication policy.

Updates
-------
Stay on stable Herdr through the Home Manager nixpkgs pin; do not use
herdr channel set preview or herdr update to bypass Nix. Config reload does
not upgrade the running server. Nix installs do not support update --handoff.
Detach preserves processes; restarting the server does not preserve arbitrary
running commands. Plan any restart after work finishes; native agent resume is
separate from process survival. Never stop the server just to apply UI settings.

Notes
-----
Kitty reserves ctrl+shift+c/v and ctrl+shift+=/-. Other ctrl+shift keys pass
to herdr. New panes inherit the active directory, but each starts a new shell;
direnv therefore runs once per pane.
